# 导演台单集制作设计

## 目标

在 `/studio` 打开当前画布后，导演能从一份分集剧本出发，确认分镜和素材，预检积分并提交生成，逐镜采用视频版本，最后预览、下载本集成片。画布与文档之间已经存在镜头来源关联，导演台沿用这套关联提供制作流程。

负责人已确认第一版在当前画布内跑通单集，以及生成前确认分镜和素材、生成后选版再合成的流程。本设计建议每张画布选定一份主剧本，并允许从当前画布加入手工镜头。跨集排期、多画布编排和剪辑时间线留到后续讨论。

## 备选方案

| 方案 | 用户体验 | 代价 |
| --- | --- | --- |
| 当前画布内增加导演台 | 从现有文档或画布接着制作，切换视图时保留当前镜头。 | 需要明确本集片单和确认状态，确保画布中的试拍与其他镜头只在导演明确加入时进入成片。 |
| 工作区单独管理剧集 | 可以从工作区管理多集，跨剧本和画布安排生成及导出。 | 需要先建立剧集与产物的归属、跨画布授权及流程状态，单集的第一条路径也要经过这套关系。 |

负责人选择第一种。导演台和现有「文档」「画布」共用当前工作区、当前画布和镜头关联，并沿用现有的镜头及生成产物。

## 三个视图的衔接

- **文档**继续编辑分集剧本、人物设定和其他资料。在分集剧本上提供「用于本集制作」，将当前文档带到导演台。通过镜头入口返回时定位对应段落并保留编辑会话。
- **导演台**从本集片单进入某个镜头，在同一处检查镜头说明、确认引用、看生成状态、比较候选和采用版本。建议在桌面显示几行只读原文摘录，窄屏可展开。「在文档中编辑」定位到对应段落。
- **画布**编辑同一批节点、生成参数、素材和连线。导演台的「定位画布」选中并聚焦该镜头。画布返回导演台时保留镜头、制作阶段和片单位置。只在该节点属于本集时恢复为当前镜头。

例如，导演在文档阅读 `S01-03 林默回头`，点「在导演台查看」，可以继续确认这镜的素材。发现要换场景图时，从导演台定位画布改成暖灯雨巷。回来仍停在 `S01-03`，能看到新的参考图并重新确认。后续采用的版本也会在画布的镜头节点显示。

三个视图以画布 ID 和节点 ID 关联镜头，以剧本文档 ID 和现有稳定镜头标识跳转原文，必要时回退到场次或行号。导演台独立记住当前镜头，画布选中上游图片或文本时仍可回到原镜。制作入口汇合到同一个导演台。现有画布镜头列表和分屏中的导出标明「全画布」，导演台标明「本集」。

## 制作流程

1. **选择剧本并确认分镜。** 从已有文档选主剧本，或通过现有文档入口新建及粘贴剧本。已有场次、动作、对白和分镜表沿用现有拆解。识别不到镜头时，在文档里展示可识别的格式和修改入口，允许使用现有创作助手整理原文。预览改动、确认剧本段落与已有镜头的匹配，再把选中的分镜同步到画布。顺序和镜头说明在确认前可调整。画布上已有同一剧本的镜头应进入确认预览，避免重复创建。
2. **确认本集片单。** 在分镜预览同屏确认哪些镜头纳入本集。只把能唯一匹配主剧本的镜头列为默认候选。多个旧节点认领同一段落时列出差异，请导演选择正式镜头。镜头副本保留原文跳转，正式归属由导演手动确认。试拍、手工或其他剧本镜头由导演主动加入。移出片单时，画布上的节点与已生成结果仍可回来使用。片单顺序来自现有画布镜序，导演台只调整本集镜头在原镜序中的相对位置。
3. **确认素材。** 汇总每镜实际会使用的角色、场景、道具及参考图，显示已有图、素材包、空槽和受影响的镜头。支持挑选工作区已有图或素材包、上传图、复用画布中已采用的图片。缺图时可通过现有图片生成入口先预检并生成参考图，选定素材后再提交依赖这些图的镜头。宫格裁切、帧提取和复杂连线可从当前镜头定位画布完成。素材确认对应明确的媒体或素材包版本。选择不带参考图的镜头时，按其模型约束预检。
4. **预检与生成。** 已确认分镜及素材的镜头可以单镜或批量预检，展示阻塞原因与本次费用，再由导演确认提交。素材图与依赖它的视频分阶段提交。镜头有对白时，按本镜音频策略决定是否生成配音。有对白配音的镜头只要求对应对白的音轨，旁白镜头使用现有旁白链路。选择保留视频原声时，镜头可以带剧本文字直接使用原声，平台字幕按现有配音时间轴生成。建议新建导演台镜头默认关闭自动尾帧继承。已有自动继承的镜头显示实际来源。继续在导演台提交前，可在画布关闭自动继承并将所需尾帧固定为首帧引用。
5. **逐镜选版。** 复用已完成的生成结果和现有候选对比。每个镜头都需要有明确采用的版本，只有一个候选也可直接采用。画布已明确采用的可用视频可继续使用，包括已明确用作该镜头的媒体。补抽时保留两种形式的采用记录。失败的视频按镜头补跑，失败的对白按句补跑，只预检所选镜头的对应阶段和所选对白句。
6. **合成与下载。** 确认本集所有镜头已采用视频且所需音频就绪后，按本集片单合成 MP4，展示进度、失败原因、预览和下载。片单后续发生变化时，历史成片继续可看，新合成使用重新确认的片单和采用版本。第一版以现有 MP4 导出器的实际限制为准，最多 30 镜、5 分钟。在提交时提前提示镜数和时长限制，渲染时仍以实际媒体时长校验。

## 保存、确认与重同步

- 原文存在现有剧本文档。导演台从现有画布节点、连线、镜序、媒体引用与任务构建界面，镜头参数和采用版本直接保存在画布。使用画布文档的可选字段保存主剧本文档 ID、上次已同步的剧本版本、本集镜头成员及必要的确认依据。老画布进入时从已有来源和镜头生成预览，确定主剧本及片单后保存，不需要新项目表或迁移老数据。
- 共享确认针对与生成相关的内容和素材版本。排序变化需要确认新片单，已有合格素材和镜头版本仍可使用。镜头描述或引用改变时标记受影响项待确认，已生成的历史结果和当前采用记录继续可见。导演可以重跑，也可以明确确认沿用旧版。其他镜头的确认和结果继续有效。画布布局、文档改名和未选中的新候选不影响确认。
- 编辑原文后，由导演发起更新预览。预览区分新增、修改、移出和已生成镜头的匹配歧义。若画布中同一项已手工修改，默认保留导演的修改并显示差异，导演可以选择用剧本更新。能从同步基线判断的改动逐项展示，基线缺失或匹配不确定时先让导演选择。其他剧本的节点、已生成媒体、在途任务与手工连线保留。
- 剧本与画布沿用各自的版本校验和草稿恢复。先保存剧本，再应用画布调整并确认画布保存成功。中途失败时明确显示失败的是剧本还是画布，重试用稳定镜头关联匹配已有节点。开始预检或合成前检查主剧本是否有未同步改动，导演可先同步，或明确以此前确认的版本继续。
- 预检与提交核对同一份已保存画布、确认的剧本依据和实际生成输入。参考图固定到具体输出或媒体，素材包和所解析的声线参数按实际版本校验。当确认依据改变时，未接单项重新预检，已经接单的任务保留原输入和回执。已提交但断线的操作以原提交号恢复回执。明确补跑失败项时重新报价并取得新提交号。任务已接单后的画布写回冲突只重试挂接结果。
- 导演台的确认是制作流程条件。导演台复用合成端点，使用明确的本集范围，由服务端从对应版本的已保存画布取片单，校验显式采用的媒体、工作区权限和音频状态，再冻结给现有导出器。本集和全画布导出分别识别提交重试及历史记录。原入口沿用全画布镜序，现有在途导出继续按已冻结内容处理。

## 实现边界与验收

- 复用 `ScriptWorkspace` 和 `ScriptSyncModal` 中的剧本编辑、段落定位、拆解与绑定。复用 `ShotList`、`VideoVersions`、`AssetPacks`、`PrecheckCostModal`、`Composition` 的现有行为。界面组件拆分、字段命名和窄屏布局由实现阶段确定。以现有节点和素材标识为准，逐项确认的依据只保留必要的信息。
- 生成重试、私有素材访问、积分确认和导出沿用现有后端。导演台的合成就绪判断和合成端点的音频判断须一致，覆盖已配对白、仅旁白及保留原声。工作区隔离及旧画布按原路径复测。
- 从 `/studio` 以有画布编辑权的工作区成员打开现有画布，先用一镜正片加一镜试拍验收最短成片路径，再用含三镜和对白的剧本验收完整流程。分别覆盖对白、旁白及保留原声。桌面和窄屏均验证 `S01-03` 在三个视图之间定位，画布更换参考后导演台仍停在原镜。
- 让一镜视频和一条对白首次失败，验证只为各自失败项重新预检，成功版本继续可选。模拟提交响应丢失，恢复回执后同一任务只冻结一次积分。验证预检后换参考图或角色声线时，未接单项需要重新预检。采用版本后再补抽一批，用可辨认的不同画面核对成片只使用已采用版本。重新打开画布，确认片单与已确认状态仍在。验证改稿重同步保留已生成视频和手工编辑，保存冲突时草稿可恢复。
- 实施后运行适用的 lint、Web 和共享类型检查、剧本同步与画布相关测试、正式 `/studio` 浏览器链路。验收实例和提交流程沿用仓库开发指南。
