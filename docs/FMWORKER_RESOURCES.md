# fmWorker 贡献系统退役

本次产品调整取消贡献客户端、共享算力池、用量上报、收益账户、贡献积分和专供贡献任务的 Flow 页面验证。旧版的 14 项贡献方法与路径覆盖 `/fmworker/*`、`/api/fmworker/*` 和 `/api/admin/fmworker/*`。产品网关对这些路径直接返回 HTTP 410。旧设备如需继续作为本地实例使用，须经普通配对流程领取新凭据。

普通配对节点使用 `/agent/*` 执行生成任务。BullMQ 继续负责后台分发。Flow 和 Muse 各自通过已配置的提供方连接执行。消费钱包继续处理充值、冻结、扣费与退款。

旧系统切换前应停写并清点在途任务、票据、已扣与冻结金额。结果不明的任务先核对提供方回执。保留已入账金额、历史流水及对账依据，独立贡献余额和结转余数只作历史记录。归档的客户端源码和固定生产清单用于追溯。Docker 发行镜像只复制普通配对客户端所需的安装文件。升级前的清点、旧凭据处理和逐笔对账步骤见[退役升级说明](FMWORKER_RETIREMENT_UPGRADE.md)。

在宿主机上复验 Python 回退时，先完成 `pnpm build`，再用安装了固定依赖的 Python 3.12 运行 `scripts/smoke-studio-python-compat.py`。专项在临时 SQLite 副本中保留历史流水和待核对冻结，通过真实 HTTP 核对旧凭据拒绝、普通配对、画布保存、取消退款及独立 Flow，并在重启后复核同一会话。
