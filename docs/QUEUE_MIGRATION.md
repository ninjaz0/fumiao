# 队列与派发迁移

原多实例预测、图片单槽、Muse 容量和 Flow 等待规则已迁入 TypeScript 插件。GPU 领取资格和请求容量检查已接入 Advanced 实际执行器，数据库读取使用 PostgreSQL 一致快照。原任务/状态 HTTP 契约、完整 worker 协议和工作台仍未切换；默认 `/studio` 继续运行完整兼容链路。

## 版本与职责

GPU、Muse、Flow、图片新增不可变的 `1.3.0`，保留旧版本及新库的 `1.1.0` 目录默认值，不自动启用提供方或升级连接。`manifest.queue` 声明策略及 `timingVersions`；当前明确兼容 `1.2.0` / `1.3.0` 特征。其他任务仍占据真实槽位，但不会借用新版本特征编造预测。历史导入继续关联最早的兼容计时版本。

核心负责快照、授权、数值计算与租约；GPU 型号/工作流资格、冷启动缓存键、Muse 外部任务/维护容量、Flow 就绪判断均属于插件。`queuePlan` 是受信任本地插件的纯函数，不执行网络请求或写入。现有远程 HTTP 插件尚未提供这些新增能力。

GPU 预测保留 FIFO、异构实例、5 秒派发余量、超过 32 个分支后的区间合并、全部可能缓存模式、冷/热启动、实时进度、未知/超时状态及偶数舍入。预测不预留执行槽。图片使用独立单槽；Muse 上游排队任务继续占据等待序列，外部任务及维护占用减少可用容量；Flow 无可靠等待时长时保留原等待原因。

## 实际执行路径

`014_queue_snapshots.sql` 增加节点公开编号/控制状态、节点能力快照及提供方健康快照。GPU v2 心跳可报告 `queue.stage`、`ready_models`、`video_steps`、`can_accept`，不能修改管理员控制状态或声明未登记模型。启用 `1.3.0` 后，领取检查节点新鲜度、就绪型号、工作流/采样资格，并分页扫描 FIFO；前 100 个不适配任务不会饿死后续可执行型号。不确定任务继续占据物理节点，避免重复并行执行。

worker 每 15 秒独立探测请求提供方，最多同时探测四个连接。Muse 读取带鉴权的就绪、模型及队列信息；Flow 读取模型及健康信息。探测有超时、响应大小上限、不跟随重定向，不保存原响应中的提示词、凭据或任务详情。数据库租约避免多 worker 重复探测；连接修订变化后，旧探测不能发布新配置可用的快照。失败/超过 90 秒的快照阻止新派发；已接收任务继续轮询，不重复提交。

实际领取/派发仍受平台连接并发、模型/工作区权限、任务租约及积分冻结约束。Muse 的上游自有任务编号用于避免重复计入外部占用。没有为读状态发起真实提供方请求。

`QueueForecasts.forWorkspace` 在一次只读可重复读事务内读取全局前序任务、节点、计时及最近 500 条样本，计算后只返回获授权工作区的任务编号、计时和预测。不会返回其他工作区的任务编号/提示词或提供方配置。关闭连接及改变修订会使其能力快照不可用。

## 对照与限制

```sh
pnpm test:queue
pnpm test
```

`test:queue` 使用固定 Python 3.12 环境和不可变原 `timing.py`，在临时 SQLite 中运行 100 个场景、984 个任务预测及 11 个小数舍入边界。新实现与原结果完整逐字段比较，涵盖多 GPU、并行通道的预测、实时进度、冷/热样本、暂停/离线、Muse 容量和 Flow 等待。

原实现合并缓存分支时从 `frozenset` 的第一个元素复制样本说明，该顺序随 Python 进程变化。测试用八个 `PYTHONHASHSEED` 运行未经修改的原算法：所有排队顺序、等待/耗时/完成区间都要求跨种子一致，新结果必须完整等于其中一个原输出，不删除样本数/来源/置信度后再判通过。目前两组历史样本场景存在这种原版元数据波动。报告记录在 `.runtime-advanced/queue-parity/report.json`；这不能代替工作台的视觉与提示说明验收。

数据库测试涵盖跨工作区前序计数及数据隔离、GPU 资格和分页领取、不确定执行占位、HTTP 只读健康探测、容量约束、旧配置探测丢弃、并发探测单次执行，以及 PostgreSQL 并发修改时读快照一致。使用本地假提供方及随机测试 schema，不调用真实模型、GPU 或支付，不修改用户数据。

Muse 上游开始/排队阶段同步已由 `1.4.0` 可选能力提供，并扩展兼容计时版本至 `1.2.0`–`1.4.0`，见[提供方绝对时间](TIMING_MIGRATION.md#提供方绝对时间)。尚未完成的部分包括原 `/api/state`、生成/预估接口、完整 Muse 准入错误/重试及状态说明、原 worker/Colab/fmWorker 管理协议和完整并行资源预算。预测器能模拟原并行通道，但当前 v2 领取只开放串行物理槽；内置 Python 桥接 worker 尚未自动报告新就绪能力，不能直接升级为 `1.3.0` 后声称 worker 迁移完成。工作台/画布 React 迁移及相同数据、尺寸、主题下的视觉验收仍须继续。
