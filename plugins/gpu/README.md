# GPU 节点插件

在 `/studio` 的设置中导入 `gpu.fmplugin.json`，启用需要的模型并设置积分价格。管理员在「GPU 节点」选择 H3 或 Breeze 并生成接入命令，再到配备所需显卡的 Linux 机器运行。安装器校验客户端 SHA-256，接入码有效期为 30 分钟。节点准备就绪后，成员可从工作台或画布提交生成任务。

2.0 将输入准备、队列与计时、节点派发、采样回执和产物规则作为沙箱策略分发。Python、模型权重和 CUDA / ROCm 运行在工作机。H3 支持文本、参考素材和首尾帧输入，Breeze 生成单声道 24 kHz 语音。宿主校验实际文件后保存私有素材并结算。

从 1.x 升级时先停用新接单，等在途任务完成后导入 2.0，再重新配对工作机。完整切换与回退步骤见[插件手册](../../docs/PLUGINS.md#gpu-20-切换和回退)。
