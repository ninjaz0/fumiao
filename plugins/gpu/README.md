# GPU 插件

GPU 推理继续使用 Python / CUDA / ROCm 等原生运行环境，主平台 API、业务与队列均为 TypeScript。推理代码和驱动不装入 API 镜像。

## 接入

1. 在管理页创建并启用 GPU 连接，为 H3 / Breeze 模型定价。
2. 点击“接入 GPU”生成 30 分钟有效的单次接入码。
3. 在 GPU 机器上运行接入页给出的安装命令。它下载 `plugins/gpu/distribution/` 的固定安装包并校验摘要，然后完成配对并启动执行端。模型权重需另行配置。

使用 `1.3.0` 及以上队列能力时，节点需声明该机器实际支持的模型、工作流和采样步数。原生 H3 要求 `h3-v6-native-inputs-turbo4`；文件结构见 [能力声明](../../docs/NATIVE_GPU.md#激活与节点声明)。未声明就绪能力的节点不会领取这些版本的任务。

首次接入后凭据保存为工作目录下的 `node.json`，权限 0600。不要提交、分享或复制给其他节点。撤销节点后该凭据立即失效。

## 成片验收

执行器本地上限为 128 MiB；插件 `1.5.0` 的服务端成片上限为 64 MiB，并严格验证原生输入指纹、采样报告、摘要、编码、尺寸和完整解码，再完成任务和积分结算。临时回传失败使用保存的结果重试，不重新渲染；永久拒绝会停止心跳并保留任务供核对。节点断线时保留执行记录，平台转为待核对，避免盲目重复生成。

插件 `1.5.0` 覆盖 H3 文生视频、普通参考图、首尾帧、视频/音频原生参考及 Breeze 文生语音。节点能力与回执要求见 [GPU 节点与生成参数](../../docs/NATIVE_GPU.md)。
