# 弗淼平台接入模块

这里保存与 fmWorker 对应的资源池和 API 模块。它们依赖现有弗淼平台的 `core`、`credits`、`worker_api` 等模块，不是独立服务器。

客户端仓库不包含平台数据库、部署凭据或整个网站源码。生产更新应从正在运行的完整平台版本应用这两个模块，并保留其他业务文件。

贡献时段、任务数上限和 CU 预算已移除。历史 `fm_resources.limits` 列保留用于兼容已有数据库，迁移时清空，调度不再读取它。资源启停、能力匹配、账号归属和结果校验继续生效。

平台集成测试：将 `FMWORKER_PLATFORM_SOURCE` 指向完整平台源码后运行 `pytest tests/test_pool.py`。
