# fmWorker v1

用户确认的实现基线（2026-11-10）：Windows 11 与 Apple Silicon macOS 桌面后台客户端，创作留在弗淼网页。Breeze、Flow 和 H3 模型执行资源按能力调度；空 Colab 实例由客户端独立管理，不领取模型生成任务。首版一个 Google 账号；Flow 使用配套 Chrome 扩展，复用用户当前 Chrome 用户与登录状态；软件提供安装向导与自动连接检测；Colab 使用浏览器 OAuth 自动返回。Google 长期凭据保存在系统凭据库，短期 Drive 授权仅可传给用户自己的 Colab 实例。

本地语音仅使用 Breeze。Windows NVIDIA 使用专用 WSL2 环境，按需安装，不要求手装 Python/Docker。Mac 首版提供 Flow 与 Colab。

Colab 必须对齐平台 H3 普通 16/20/32/50 步、4 步 Turbo、首尾帧、图片/视频/音频参考、480/768 和 5/10/15 秒。以当前平台相同 ComfyUI、权重与输入语义为基准。必须通过真 GPU 验收才标为已验证；不能以代码存在或降低显存检查冒充验收。

各资源独立开关，不购买额度。贡献时段、任务数上限和 CU 预算功能已移除。0.4.0 支持多台 Colab 并存：先明确选机型，“创建实例”仅建空实例；“一键部署”总是新建 G4 部署 H3，H3 直接接入模型工作队列。暂停仅停止模型接单，退出桌面不释放 Colab；平台没有空闲或最长运行回收，仅接受手动释放。Google 自身回收无法阻止，确认其已回收时清理实例连接记录，不把仅连接掉线当作实例消失。

Google AI 套餐与 Colab 权益分别记录。优先只读查询 user-info；不能访问时用 ccu-info 原始资格列表。必要时提示补充同账号授权查询套餐，失败显示未确认，不能从余额猜 Pro/Ultra，不能通过批量创建 GPU 探测。

成功且服务端验收的任务按非赠送积分支付部分奖励 70%，不可提现，本人任务不奖励；使用整数账本与余数累计，避免小任务舍入丢失。重复回传不重复奖励，失败退消费者积分、不奖励贡献者，已经发生的资源消耗仍记录。

界面为 Operate 模式，沿用弗淼浅色系统字体与蓝色焦点，纯功能文案。主要页面：资源、Google 账号、贡献记录、设置。状态必须源于后台，不显示虚构在线或收益。首次连接、安装进度、错误恢复、暂停和退出必须可用。

发布条件：Google 真实登录/续期与 Flow 生成；至少一种 Colab 配置通过完整 H3 矩阵；Windows NVIDIA Breeze 安装/推理；Drive 缓存/断电释放；签名安装包；确认 Breeze 书面授权覆盖运营方式。模拟测试与真实验收分别记录。
