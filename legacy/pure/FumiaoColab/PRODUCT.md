# FumiaoColab

原生 macOS 应用。先登录弗淼 AIGC，再绑定 Google 账号，一键在一台 Colab GPU 上部署 MiniMax H3，并以当前弗淼用户创建的配对凭据接入现有算力池。实例归属由弗淼服务器决定，不由客户端自报。

仅保留算力实例、账号、部署、额度、运行时间、自动释放。没有视频创作、聊天、其他模型、Windows 端和作品库。外观沿用用户提供的 EasyColab 两卡截图：浅蓝灰底、白色圆角卡、细描边、蓝色线性图标、系统中文字体。

使用 EasyColab 的 google-colab-cli 分配方式及 DiffSynth MiniMax H3 BF16 管线和分级内存策略。双主干是同一机器内的文本编码器与 DiT，并非双机。只管理本应用创建的会话，不接管或释放其他应用的实例。真实运行前需要用户登录两个账号。

平台固定为 https://nvmes.com。登录密码不保存，弗淼会话放入 macOS 钥匙串。Google 授权及 Colab 会话独立保存在本机应用支持目录。云端只收到单实例配对码和实例密钥，不收到弗淼登录密码或登录会话。
