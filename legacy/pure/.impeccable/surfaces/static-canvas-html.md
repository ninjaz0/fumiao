# 画布

Mode: Operate. Target: static/canvas.html; React source: canvas/src. 本记录限定于共享画布，基础布局按 2026-11-05 的实现与本地验收截图整理；文本生成器的 2026-11-07 更新与当前证据见 [对话与画布写作](static-chat-js.md)。 2026-11-09 的模板、素材包、候选、旁白及成片扩展见 [分镜制作流程](static-canvas-production-flow.md)；旧 finish 记录不扩展为该流程的验收。

## Direction

单团队共享创作画布。所有已登录成员查看和编辑；创建者或管理员删除。方向契约以 `static/canvas.html` 的首个 body 注释为准：内容节点与引用关系构成共享创作空间，进入画布、连接文本和图片、调用现有服务生成、再次打开已保存结果。

参考用户指定的即梦新版节点画布截图，采用 code-led 实现；沿用弗淼彩色品牌、浅深中性外观、系统中文字体与安静的深色操作按钮。此表面的点阵和悬浮控件不改变主工作台的设计规范。第一版范围为文本、图片、视频、便签、平移缩放、选择与引用连线；不显示时间线、3D 导演台或图片精修入口；文本 AI 生成以选中节点下方的输入区呈现，不使用独立聊天侧栏。

## Implemented layout and appearance

- 完整视口工作区使用浅灰底（`--cv-bg: #f5f5f5`）和点阵。点阵跟随视口平移、随缩放调整间距，点保持可见尺寸；60% 缩放仍能辨认。深色外观使用同一布局及画布局部颜色变量。
- 左上为品牌、项目名称、节点数量和文字保存状态；右上为搜索、生成历史及资产入口。桌面左侧插入栏宽 48px，左下为选择、手形、缩略图、连线显示、缩放和撤销重做。
- 节点以内容为主体，文字与便签可调整大小，图片保留完整画面。节点顶部的类型图标、可编辑名称与颜色标记在缩小时反向缩放，标题容器同时补偿宽度，颜色标记保持与节点右侧对齐。
- 选中对象才显示其工具条；单个文本、图片或视频节点显示对应生成器。桌面工具条通常在节点上方；节点顶部进入 150px 区域时放在节点下方，避开名称。生成器宽 520px，位置按视口边界限制，并为下方工具条留出间隔。文本生成器按实测高度为底部视口栏保留 80px 空间；完整结果回写原节点，可撤销，切换选择不丢失已受理回写，手动文字冲突时保留当前文字并提示重新生成。
- 760px 及以下使用窄屏布局：插入栏宽 42px，工具条固定在右上方，生成器左右各留 12px、位于底部视口栏上方，最大高度为 46dvh；比例与分辨率浮层按屏幕宽度展开。移动截图中的生成按钮、参数、引用列表和视口控件均留在屏幕内。
- 正文使用系统中文字体（14px）；节点名称和参数标签为 12px。节点圆角 10px，工具条圆角 10px，桌面生成器圆角 16px。白色悬浮操作面使用轻阴影；蓝色焦点与选中轮廓、便签色块和小色标承担状态区分。

## Implemented interaction and service boundary

- 文本右侧可新建下游视频，正文作为输入参考；连接图片后生成器显示对应缩略图。引用按次序排列，可前移或移除。
- 连线有类型约束：文本、图片可作为图片或视频节点的输入；禁止自身引用、重复连线和循环，每个目标最多 9 张参考图片。便签用于注释。引用尚未就绪时显示具体节点并阻止生成。
- 选择、框选、多选、拖动、缩放、平移和触屏捏合均由现有画布交互实现；一次拖动记为一次撤销。节点、连接和文档编辑可撤销，已提交任务独立于文档撤销。
- 资产选择器和生成历史复用已有真实资产与任务。生成器只显示现有服务支持的图片／视频参数；任务排队、运行、失败与完成显示真实状态，提交先保存文档并使用请求标识避免重发。
- 图片生成关闭时禁止提交图片生成；已有图片仍可整理和用于视频参考。验收不私自打开收费生成。

## Persistence and shared editing

文档修改在停止编辑约 800ms 后自动保存。服务器以 `expected_revision` 校验版本，返回新的 revision 和规范化后的已保存文档；没有后续本地修改时，编辑器采用服务器返回的标题和文档。

本地仅缓存未获服务器确认的草稿，键包含用户 ID、项目 ID 和当前编辑标签页的 ID；标签页 ID 保存在 sessionStorage。服务器确认当前草稿已保存后移除对应本地缓存。存在更新中的后续修改时，继续保留并保存最新草稿。

共享编辑采用版本冲突保护。遇到 409 或恢复了旧版本草稿时停止继续覆盖，显示“画布已被其他成员修改，你的修改已保留”，提供下载本地副本和重新载入；重新载入前再次确认。此实现没有逐字符实时合并。项目删除入口遵守服务端返回的创建者／管理员权限。
