# 分镜制作流程

Mode: Operate. 记录日期：2026-11-09。范围是现有画布及主创作区素材包入口的局部扩展；代码已实现，并于2026-11-09通过真实创作闭环验收后上线。基础画布布局见 [画布](static-canvas-html.md)，既有对话行为见 [对话与画布写作](static-chat-js.md)。

## Direction and boundary

方向来自 `work/production-flow-20261109/PLAN.md` 的 review contract：可编辑模板 → 分镜 → 可复用人物／场景参考 → 明确提交候选与确认总价 → 比较采用 → 镜头旁白 → 最终预览和导出。延续即梦式中性浅深外观、系统中文字体、线性图标、既有弹窗／工具栏／模型菜单及积分规则；无新身份设计或额外装饰体系。

创建模板和采用分镜不触发视频或语音生成。新增 H3 首尾帧、视频／音频参考能力另行实验，10次推理的结果与限制另记在验收报告，本表面没有将它们作为已开放控件。

## Implemented flow

### Templates and AI proposal

- 活动宣传片、产品展示、人物短片三套模板均可选横版／竖版，包含六个可编辑的五秒镜头及共享参考图节点。
- AI 分镜沿用工作区对话配置、权限、价格和退分规则；默认请求六个镜头，可接收 1–12 个镜头。每项可改名称、画面、旁白和 5／10／15 秒时长；文字生成与视频生成是不同操作。AI 请求引导自然朗读每秒约 2–3 个汉字，5 秒不超过 12 字、10 秒不超过 25 字、15 秒不超过 35 字；这是拟定建议，不是强制校验或精准语音时长保证。手动字段与 API 仍允许最多 300 字旁白。
- 提案需点击“采用分镜，不生成视频”，不自动提交视频。需求和可用提案按用户、工作区、画布存于本地草稿；新回答格式错误时保留需求与此前可用提案，显示普通文字解释和带价格的重新拟定动作。解析在内部处理，支持数组／shots 对象和包裹代码块，不提供原始 JSON 修复字段。
- 同族模型菜单具有自身的主题和控件样式，不依赖聊天页容器；上下方向键、Home／End、Escape、外部点击与焦点返回沿用现有交互。

### Reusable reference packs

- 包含名称、用途、说明及 1–9 张有序图片；用途为人物外观、服装、场景、风格、产品细节。可上传图片或从当前工作区资产选择，编号表示选入顺序。
- 画布生成器和主创作区参考菜单均可打开共享素材包界面。包受工作区访问控制；修改检查版本，提交生成时再次校验版本，将名称、用途、说明、有序图片和版本快照固定到任务中。后续修改不改写历史任务。
- 所有有权访问空间的成员可编辑；删除限拥有者或管理员，被画布引用时阻止删除。删除包保留原图片。当前包过期／有冲突时提示刷新后重新选择，不静默替换已提交参考。

### Candidates, adoption and frame reuse

- 画布视频参数选择一个或两个候选；两候选确认弹窗直接呈现数量、总价及分别退分语义。初次提交在同一事务接受全部候选并冻结费用；同一请求重试不新增任务。候选独立完成、失败／取消及结算。
- 固定种子时第二个候选为原种子加一；模型允许随机种子时仍使用原模型规则。任一候选排队／运行时阻止同节点继续发起生成；每个候选保留自己的状态与取消／采用操作。
- 比较可以从头同时播放或同时暂停，左右选择不同版本；显示尺寸与时长、参考图片、模型、采样、种子和提示词，差异值加粗。时长优先使用实测，缺少实测的旧 H3 结果使用下述帧数回退。采用明确版本后保持固定，不随后续成功任务切换。
- 引用或参数变化显示重新生成提示，保留采用画面。视频取帧记录来源媒体与时间，保留现有单图首帧裁切预览；这些功能不证明新增首尾帧／视频／音频输入实验已通过。

### Shot narration and final composition

- 镜头列表保存顺序，提供上移、下移、移除、旁白和按序镜头 ZIP 导出。每镜头显示时长取视频时长与当前已采用成功旁白实测时长的较大值，汇总为约计总长；未采用的新旁白不计入。视频优先取实际时长，缺少实测的旧 H3 5／10／15 秒结果分别按既有 124／243／362 帧、24fps 回退；其他缺失时长沿用任务或节点请求值。列表估计不替代合成时的真实媒体探测。成片预览以合成后的 MP4 为准；已移除将原片段顺序播放当作成片的入口。
- 旁白通过 Breeze 队列提交，文字与音色描述各最多 300 字，使用配置的语音价格。界面分别解释模型未开放、未定价、余额不足，并显示等待／生成／失败／取消及明确的重试。
- `narration_pending` 与当前 `narration_job` 分离。旧音频在替换任务等待或失败时仍可播放；替换仅在成功且文稿、音色描述仍匹配时自动采用。期间编辑内容则呈现待采用音轨和“使用生成时的文稿与旁白”。失败／取消按任务规则退分，重试是新的收费生成。
- 界面在视频未就绪、已填写旁白但尚无成功音轨、新旁白仍在排队／生成或文稿与当前音轨不匹配时禁用“合成预览”，按镜头顺序显示第一个问题及镜头编号，例如“镜头 2 的旁白仍在生成”。需要先补齐视频、生成／更新旁白或清空不使用的旁白。服务端继续独立检查媒体、权限、版本及旁白状态，界面禁用不替代后端校验。
- 合成固定本次顺序与已采用／当前媒体，按真实时长拼接。旁白替换对应镜头原音轨；旁白较长时延长最后一帧，未配旁白的镜头保留原音轨或补静音。统一为 24fps H.264／AAC，保持画面完整，按首镜头画幅等比容纳，长边不超过 1920px。
- 字幕按句和文字长度分配旁白时段，不是 ASR 或逐字对齐。MP4 含可选 mov_text 字幕轨，同时提供独立 SRT 和浏览器 VTT；预览与 MP4 下载引用相同媒体文件。
- 结果进入工作区资产库。采用和 CPU 合成不另扣积分；每次 1–30 个镜头、总长最多五分钟，提交预留存储并受配额保护。每空间同时只接受一个待合成／合成中任务。

## Implemented visual rules

以下数值来自最终样式层叠，而非早期设计意图。`DESIGN.md` 记录可复用规则，本节保留本表面具体尺寸。

| 部位 | 当前规则 |
| --- | --- |
| 主题与文字 | 复用画布浅深语义色；正文 14px，表单标签／说明 13px，参数／镜头状态／比较规格 12px。主要按钮用主题正文色与反色文字。 |
| 模板入口 | 桌面三列、12px 间距；600px 以下单列、8px 间距。模板 12px 圆角、16px 内边距，窄屏内边距 12px。 |
| 画布弹窗 | 16px 圆角，默认 24px 内边距；镜头列表宽 `min(740px, calc(100vw - 32px))`。 |
| 镜头滚动区 | 桌面最大高 `max(180px, calc(100dvh - 400px))`，600px 以下为 `max(180px, calc(100dvh - 440px))`。计数与导出在上，成片操作在滚动区外。 |
| AI 提案 | 纵向布局，镜头编辑区 `min-height:120px`，自身滚动；桌面上限 `min(48dvh, calc(100dvh - 420px))`，600px 以下为 `max(120px, calc(100dvh - 440px))`。底部计数与采用按钮独立于编辑区。 |
| 共享模型菜单 | 最终自包含触发器为最小高 36px、圆角 8px、间距 7px；图标 15px、箭头 14px。菜单最小宽 200px、最大宽视口减 48px、最大高 45dvh，内边距 6px、圆角 14px；选项最小高 40px、圆角 9px，以灰底和右侧 17px 对勾显示当前值。 |
| 字段 | 1px 主题边界、8px 圆角、10px 内边距；标签间距 6px。文字与错误保留可读长度，不以装饰卡片分隔每个字段。 |
| 素材包 | 行缩略图 56px、8px 圆角；可选区域 10px 圆角，灰底加对勾；行编辑／删除独立。图片网格最小列宽 90px、间距 8px、最大高 280px；素材包列表最大高 52vh。 |
| 版本比较 | 始终两列；桌面间距 16px，600px 以下 8px，视频按视口高度缩放。版本选择器在窄屏中纵排标签与选择框；长规格内容自身滚动。 |
| 旁白 | 桌面缩进 32px，600px 以下取消缩进；音频控件高 40px、占满内容宽度。旧旁白、失败说明和带价格重试就近显示。 |
| 成片 | 位于镜头列表之后，以细分隔线和标题分组；预览播放器 12px 圆角、宽 100%、最大高 50vh，结果操作可换行。 |

模型触发器的复核文字曾引用早期 34px 尺寸；本记录以最终 CSS 的 36px 为准。此差别没有被转写为新的视觉修正事项。
