# 参考图片导入表面记录

## Overview

模式：Operate。沿用 [DESIGN.md](../../DESIGN.md) 中现有工作台、资产库和素材包控件，帮助创作者把已有图片加入当前输入。本轮仅完善引用入口与导入语义，不改变全站视觉体系或主题 tokens。

记录日期：2026-11-10。本轮实现已完成本地交互、排队载荷及相关回归验证；最终限定复核结论为 `ship`，唯一新增问题已解决，范围内没有剩余发现。已发布至正式站 `20261110T063253Z-reference-import`，Chrome 实测资产页点选加入参考区、素材包入口加载正常；本轮没有新增 GPU 或外部供应商真实生成验收。

实现来源：[studio.js](../../static/studio.js)、[studio.css](../../static/studio.css)、[AssetPacks.tsx](../../canvas/src/AssetPacks.tsx)、[asset-packs.css](../../canvas/src/asset-packs.css)、[main.tsx](../../canvas/src/main.tsx)、[chat-entry.tsx](../../canvas/src/chat-entry.tsx)。

## Colors

资产库选中图片使用既有正文色轮廓和带对勾的状态标记；素材包选图使用同族轮廓、选择顺序数字和“已添加”文字，不只依赖颜色。主要导入按钮使用正文色底与反色文字，整包操作保持次要按钮层级。

资产库“已添加”计数使用局部 `color-mix(in srgb, var(--secondary) 90%, var(--text))`，浅色结果约为 `#676767`；最终复核计算对比度为 5.33:1。这是本次状态文字的对比度修正，不修改全局辅助文字 token。素材包继续复用现有浅深主题变量；本轮保存的截图为浅色，不据此宣称深色视觉验收已完成。

## Typography

沿用系统中文无衬线字体。资产库计数及素材包正文为 14px，素材包详情标题为 18px、字重 600。素材包说明保留换行，长名称和说明可折行；没有新增展示字体或装饰文案。

## Layout

“从资产选择”进入完整图片资产库，复用已有分类、范围筛选与图片网格；顶部以已添加计数和“完成选择”替代批量操作。底部创作框继续显示当前草稿，导入期间保留提示词与生成参数。

素材包列表保持原有分隔行、56px 缩略图、名称、用途、图片数和摘要；点击行进入包内详情。详情按返回入口、名称与用途、说明、图片网格、导入操作排列。图片网格桌面最小列宽 140px、间距 12px；600px 及以下为两列、间距 10px。图片完整缩放显示，网格最高 48vh 并独立滚动；说明最高 120px 并独立滚动。底部操作可换行，窄屏的“导入所选图片”占满一行。

## Shapes

包内图片使用圆角 12px，与现有画布面板尺度一致；主要导入按钮沿用 10px 圆角，次要按钮沿用 8px 圆角。资产库计数旁按钮沿用同族尺寸。本轮复用这些已有局部尺度，不把它们提升为新的全站规范。

## Components

### 完整资产库导入模式

从创作框的“从资产选择”进入图片历史视图，点击可用图片立即添加，不另设一次提交选择的步骤。已有直接引用与素材包引用一起参与去重；已添加图片显示对勾、轮廓和可访问状态，重复点击不重复加入。这里只显示成功且在当前空间可访问的生成图片和可用图片资产，隐藏失败、运行中、已移除或不可访问的结果，以及批量删除等管理操作。普通资产浏览保持原有历史与管理能力。

“完成选择”或 Escape 退出导入模式，返回先前页面、分类、范围与滚动位置，保留已添加图片。导入不替换提示词、模型、画幅、质量、时长或保留的种子。

### 素材包内选图与整包引用

点击素材包行仅打开内容。包内点击图片设置本次选择顺序；已经引用的图片标记“已添加”并禁用。主要操作“导入所选图片”只建立独立图片引用，不带入该素材包的说明或版本关联，之后不受素材包编辑影响。次要操作“导入整个素材包”保留整包图片、说明与版本关联；已有同版本包显示“已导入整包”，版本变化时可更新整包引用，也可明确移除整包引用。

整包导入保留其他直接引用和其他素材包引用，并按素材 ID 去重。新建、编辑和删除素材包入口保留，删除权限与“原图片会保留”的说明沿用现有流程。

### 画布导入

选中图片导入后创建独立图片节点，并连接到目标图片或视频节点；全部新增节点与连线作为一次可撤销的文档变更。新节点放在目标附近的可用位置。整包导入则保存包 ID 与版本关联，保留已有其他引用；不把整包引用伪装成独立图片节点。

### 限制与错误

图片上限仍为九张，H3 全能参考总上限仍为十二项，计数包含直接素材与素材包的去重结果。导入前重新核对可访问图片与容量；失败不留下半批导入。主创作区首尾帧导入继续遵守两个槽位及图片比例约束，比例不匹配时回退整批帧变更；画布首尾帧仍使用明确的首帧、尾帧选择器。其他模型的实际引用限制继续由既有模型校验执行。

## Do's and Don'ts

### Do:

- **Do** 让图片导入保持当前草稿，依素材 ID 去重并明确展示已添加状态。
- **Do** 区分独立选图与整包的说明、版本关联，保留其他已有引用。
- **Do** 将本地交互、排队载荷、线上发布和真实生成验收分别记录。

### Don't:

- **Don't** 在导入模式暴露批量删除等管理动作，或把退出选择当作清空已添加图片。
- **Don't** 将零项测试、合成测试素材或本地截图称为完整覆盖、生产验收或真实生成成功。
- **Don't** 为这次局部导入交互改写根设计规范、主题 tokens 或既有素材包管理能力。
