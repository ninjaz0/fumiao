# H3 原生输入表面记录

## Overview

**Creative North Star: "既有即梦式创作区中的明确输入角色"**

这是现有中性创作区的局部扩展：先选择 MiniMax H3，再选择“全能参考”或“首尾帧”，添加素材并描述画面，最后设置格式、时长和提交。沿用 [DESIGN.md](../../DESIGN.md) 的字体、主题与线性图标，不建立新页面或独立视觉系统。方向依据是 [static/index.html](../../static/index.html) 的 `H3 DIRECTION`；本文件只记录本轮发布代码体现的表面。

**Key Characteristics:**
- 模型之后、格式之前的紧凑模式菜单。
- 按类型标记的参考素材，或位置明确的首帧／尾帧槽位。
- 同一编辑器内完成引用、移除、交换与预览，窄屏保留这些操作。

## Colors

不新增 H3 强调色。主创作区复用 `--surface`、`--hover`、`--line`、`--text`；画布复用对应的 `--cv-*` 变量。图片与视频缩略图承载素材差异，音频使用线性麦克风图标，类型与编号同时用文字标明。模式选中状态沿用菜单对勾和既有灰底。

浅深主题使用现有变量切换；本轮保存的视觉证据为浅色，不据此宣称深色已完成视觉验收。

## Typography

沿用根样式的系统中文无衬线字体，正文为 14px；主创作区行高 1.55，画布为 1.5。素材编号与卡片操作使用 frontmatter 中的标签字号；主创作区上传限制、视频声音选项为 13px。没有新增标题、展示字体、全大写标签或装饰性说明。

## Layout

主创作区的 Muse 与 H3 共用参考素材 host 和卡片样式。普通参考入口固定宽 84px、高 100px，提示词紧随其后（桌面间距 18px），不预留图库宽度。多份素材以最多三层缩略图叠放并显示总数量，点击后在菜单中预览、引用、排序、移除或继续上传；首尾帧保留独立双槽，宽屏使用 206px 占位。容器宽度 600px 及以下统一将参考区与提示词分行，提示词最小高度 100px。参数与引用／高级工具、积分／生成按钮分组；容器宽度 760px 及以下操作区独立一行，560px 及以下参数区预留两行，260px 及以下使用三行网格。各模型按同一容器规则布局，避免模式控件数量不同造成外框跳变。资产页留白随 ResizeObserver 测得的输入框高度变化并增加 44px；浮动提示词最多 min(240px,25dvh)，超出部分内部滚动。

画布将素材条放在所选视频节点生成器的提示词上方，仍使用现有 760px 响应式布局和可换行参数行。参考条横向滚动；首尾帧始终保留两个固定槽位，中间是交换操作。预览宽度最多 960px，并为视口两侧保留合计 32px；高度受动态视口限制，完整媒体使用 contain，避免缩略图裁切影响预览。

**The Visible Roles Rule.** 首帧和尾帧由明确槽位表达；全能参考由素材类型与类型内编号表达。素材数量不能替代用户选择的模式。

## Elevation & Depth

素材卡与帧槽用主题表面和细边界区分，不新增卡片投影。预览复用现有模态层级：主创作区使用既有原生 `dialog`，画布使用 `showModal()` 打开的原生 `dialog`，配合既有画布阴影及半透明黑色遮罩。关闭后恢复触发位置的焦点，Escape 关闭预览。

## Shapes

素材卡与帧槽共享 frontmatter 中的圆角；缩略图在卡片内裁切，完整预览不裁切。主创作区卡片尺寸为 76×82px，画布为 72×78px，这是各自既有生成器密度下的局部尺寸，不提升为全站卡片规范。添加素材使用虚线边界，移除为右上角圆形按钮。引用 chip 是与正文行内排列的轻灰小块。

## Components

### 模型后的模式菜单

只有 MiniMax H3 视频显示“全能参考”和“首尾帧”；它们使用既有模型／参数菜单样式、图标、箭头和选中对勾。切换模式会转换素材角色和提示词引用。主创作区暂存全能参考草稿，切回时保留素材；若帧模式的提示词未修改，可恢复原参考文字。画布切至首尾帧前，要求先将素材包图片放入画布并取消素材包，避免包内图片隐式加入固定槽位。

### 全能参考

图片最多九张，视频最多三段，音频最多三段，合计最多十二个；视频和音频每段 2–15 秒，各自同类总时长不超过 15 秒。输出时长不能短于参考视频。视频有声音时，可明确勾选是否同时参考声音；不把音轨默认当作独立音频引用。服务端重新核对类型、时长、数量、当前工作区权限及所选视频的音轨。

主创作区通过 `@` 或参考菜单插入引用，菜单支持素材前移及拖动排序；画布通过素材下方“引用”按钮插入。提示词显示“图片1／视频1／音频1”等 chip，图片 chip 带缩略图；提交按类型写入 `<Picture n>`、`<Video n>`、`<Audio n>`。chip 以素材 ID 保持关联：移除素材时删除它的引用，余下引用按原素材重新编号。画布不新增独立素材排序按钮，但序列变化时同样按素材身份重映射。

**The Stable Reference Rule.** 编号可以随删除或顺序变化更新，已有引用不能因此指向另一份素材。

### 首尾帧

支持仅首帧、仅尾帧或两帧，只接收图片。两槽之间的交换按钮也支持将单张图片从一端移到另一端；每槽可单独移除，点已有图片打开预览。添加图片后比例显示“自动”，画幅选项禁用，分辨率仍可选。第二张图片比例不匹配时保留已选图片并拒绝填入；代码采用对数比例差不超过 0.035 的容差。

帧模式使用普通运动／过渡描述，参考 token 转为对应的“首帧”“尾帧”语义；不保留脱离当前帧角色的引用。主创作区与画布均支持上传、拖入和粘贴；上传期间展示忙碌状态，并阻止相关编辑／提交。

### 媒体预览

缩略图按钮提供类型或帧角色的可访问名称。图片完整显示，视频与音频提供原生播放控件；关闭按钮可键盘操作。画布预览位于浏览器顶层模态层，不受画布节点缩放或节点裁切影响。预览不是裁剪、编辑或新建任务入口。

### 复核证据
